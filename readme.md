# Bodycam_EXPER1ENCE

This project was made for the roblox game BLackhawk Rescue Mission 5, but could be used mostly in any scenario.

The controls:
* Quit: Ctrl + Q
* Hide: Ctrl + H
* "Night" vision: Ctrl + N

> Keep in mind, night vision in this project DOESN'T give any real advantage in game, it is simply an effect.

## For developers

This project was made with Electron.js, if you wish to modify it. Please do it with a fork.
